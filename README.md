# Cotización del Dólar a Pesos Argentinos 📈💰

Este proyecto en PHP consulta una API externa para obtener la cotización del dólar en pesos argentinos. Permite obtener datos actualizados y procesarlos de manera eficiente.

## 🚀 Características

- Consulta automática a la API de cotización del dólar.
- Formateo y presentación clara de los datos obtenidos.
- Código modular y fácil de extender.

## 📦 Requisitos

Antes de comenzar, asegúrate de tener:

- PHP 7.4 o superior.
